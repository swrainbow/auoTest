# 节点生命周期参考

任务节点的生命周期阶段与典型 Hook 绑定点：

- **创建时**：节点任务创建时触发，常配“校验 Hook”（货物状态、锁定状态等）。
- **执行中**：节点执行过程中触发，常配“流程 Hook”“机器人 Hook”。
- **离开前**：节点完成离开前触发，常配“后处理 Hook”“回调 Hook”。
- **异常分支**：执行失败/取消路径，Hook 顺序与重试语义需单独验证。

## 测试关注点

1. Hook 必须出现在正确的节点与生命周期阶段（容易错位到同名节点）。
2. 同一生命周期多个 Hook 时的顺序在保存/重载后保持不变。
3. 参数修改后重载验证新值生效，旧值不残留。
