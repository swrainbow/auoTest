# 地图准备

## 运行参数

| 参数 | 填写规则 |
|---|---|
| 地图名称（mapName） | 必填。使用本次准备任务给出的完整名称，保留大小写。 |
| 楼层（floor） | 创建地图时使用。优先采用任务指定的楼层，省略时填写 1。 |

## 准备步骤

1. **进入地图编辑页。** 在左侧导航展开「地图」，单击其下的「地图」子菜单。确认页面路径为 `/tkmap/mapDraw`，画布左上角出现地图选择器。
2. **按完整名称查找。** 单击画布左上角当前地图名称旁的下拉箭头，等待地图列表加载完成。在这个下拉列表中逐项核对名称，列表可滚动时查看后续选项。例如，目标为 `test00` 时，`test001` 属于另一张地图。
3. **已有则复用，缺少则添加。** 如果列表中有目标地图，单击该项切换过去；如果它是当前地图且菜单项已禁用，直接收起列表。已有地图沿用原配置，转到第 5 步。确认列表中没有目标名称时，单击同一下拉列表里的「添加地图」，等待同名弹窗出现。菜单项的可访问名称是「添加地图」，左侧加号为图标。
4. **填写并保存。** 在弹窗内的「请输入名称」输入框填写 `mapName`，在「请输入楼层」输入框填写 `floor`。测试站点的楼层输入框初始为空；调用方省略楼层时必须填入 `1`。其余选项保留初始值。单击一次「确定」，等待弹窗关闭和页面自动切换。
5. **核对结果。** 读取画布左上角的当前地图名称，确认与 `mapName` 完全一致。对于新建地图，先确认保存后已自动打开目标地图，再展开下拉列表核对目标名称已出现，最后收起列表。记录地图名称、处理结果（新建或复用）和实际显示的当前地图名称；新建时同时记录填写的楼层。

如果列表加载失败，先恢复列表读取，再决定是否新增。若保存结果不明确，重新查看列表和当前地图名称，避免重复提交。若地图已出现在列表但页面仍停留在原地图，记录“已创建，自动切换未确认”及实际显示的名称。页面如显示「关联服务异常」，可单独记录提示；服务关联由后续准备步骤处理。

## 脚本定位与持久化验证

- AutoTest 在新浏览器会话中先 open `/tkmap/mapDraw`，紧接 `{"type":"ensure-map-session"}`。此操作等待地图 iframe 或登录表单，按需使用平台 target 凭据登录并返回地图。若前置准备已建立登录会话，可直接进入地图选择步骤。

- 外层导航的子菜单链接指向 `/tkmap/mapDraw`。画布、地图菜单和添加弹窗在 `iframe#hyjalIframe` 内，对这些控件使用该 frame 范围内的定位器。
- 首次进入和刷新后，地图名称可能暂时显示 `--`。等地图选择器 `.show-circle-btn[role="button"][aria-haspopup="menu"][tkmapid]:not([tkmapid=""])` 就绪，在菜单收起时按 `ArrowDown` 展开。在同一 iframe 的 `.map-dropdown-menu[role="menu"]` 中等当前地图的禁用项出现，按完整名称匹配可用的 `menuitem`，用 `Enter` 选中。创建时以同样方式激活「添加地图」。若目标已是当前地图，在选择器上按 `ArrowDown` 收起。等待菜单隐藏，再用左上角同名按钮核验。
- 进入地图编辑页后直接使用 `ensure-map-in-menu`。该动作负责打开菜单、按完整名称复用或新增地图，并核对切换结果。验证持久化时，重新进入地图编辑页，调用同一动作并设置 `existingOnly: true`。若这次找不到目标，报告回读失败并保留第一次保存的结果。
- 需要记录一张已有地图的实际楼层时，在该操作同时传入 `existingOnly: true` 和 `recordFloor: true`。运行时按目标地图 ID 回读详情，核对 ID 和地图全名，将返回的楼层写入运行日志。`floor` 用于创建地图，已有地图的实际楼层以回读结果为准。
