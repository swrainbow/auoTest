# Hook 配置测试

## 业务概念

- Hook 绑定到任务节点的生命周期阶段。
- 支持类型、字段和合法值必须从业务 Schema 获取。

## 测试生成步骤

1. 读取真实任务图并确定唯一 nodeId。
2. 获取节点及 Hook Schema，并校验需求合法性。
3. 形成业务步骤、参数和预期结果。
4. 使用 e2e 操作真实界面，不得直接改前端状态代替 UI 测试。
5. 通过 UI 和只读 API 验证保存及重新加载结果。

## 约束

- 不仅凭“第二个移动节点”等模糊文本直接定位。
- 不猜测 Hook 枚举、字段名或运行时业务规则。
- 断言变更必须重新审核，不能为通过测试自动降低检查要求。
