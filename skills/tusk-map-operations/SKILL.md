# 地图操作

## 选择地图和模式

1. 从请求确定目标地图和动作。用户说“当前地图”时读取左上角名称；给出名称时按全名核对。AutoTest 已知入口为「地图 → 地图」(`/tkmap/mapDraw`)，该站点的地图控件位于 `iframe#hyjalIframe`。若页面仍在加载，等到实际地图名称出现。
2. 根据请求选择相应入口。顶部工作模式从左上角地图名称旁的工具栏进入，入口图标随当前模式变化。展开后按下表中的菜单原文选择，并以当前选中项或目标模式特有的控件核对结果。已经在目标模式时直接进行该操作。
3. 左下角的「标准模式／专业模式」是另一组选择。用户指定，或某项操作明确依赖其中一项时，在左下角切换并核对选中状态。例如“进入专业模式”只需操作左下角；“在标准模式下修改点位”需同时核对顶部的「编辑模式」和左下角的「标准模式」。只要求切换时，核对选中状态即完成。

| 顶部菜单项 | 何时选择 | 操作配置 |
| --- | --- | --- |
| 浏览模式 | 查看地图、定位对象 | [浏览模式](references/view-modes.md#浏览模式) |
| 回放模式 | 查看历史回放 | [回放模式](references/view-modes.md#回放模式) |
| 地图切片 | 用户要求进入或操作地图切片 | [地图切片](references/view-modes.md#地图切片) |
| 热力图 | 用户要求查看热力图 | [热力图](references/view-modes.md#热力图) |
| 编辑模式 | 修改已有点位等地图对象 | [编辑模式与修改点位](references/edit.md) |

## 执行或补充操作

- 执行时按目标模式查找对应操作，使用本次请求的对象标识和参数。截图中的地图名、数字及当前选项只用于识别界面。
- 对尚未收录的步骤，可根据当前页面的标签、控件提示和状态补足。若有多个可能的目标，或提交效果仍然不明确，说明已确认到哪一步、还缺哪项信息。生成自动化用例时只使用执行器已有的动作及有依据的定位方式。
- 用户提供新截图或操作说明并要求补充 skill 时，按[操作条目模板](references/operation-template.md)更新对应模式的章节。模式内操作增多时可拆成独立文件，在上表更新链接。
