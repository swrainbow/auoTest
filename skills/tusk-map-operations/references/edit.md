# 编辑模式

## 修改点位的机器人约束

**输入**　目标地图、能唯一识别点位的编号或名称、用户要求的机器人约束值。示例截图位于「编辑模式」和「标准模式」；专业模式下该面板的布局待核实。

| 步骤 | 操作与核对 |
| --- | --- |
| 定位点位 | 在目标地图核对点位标识，使用现场已确认的入口打开「修改点位」。截图从面板已打开处开始，打开面板的手势待补。上方表格的数字缺少列标题，不能据此认定目标点位。 |
| 找到字段 | 在「修改点位」面板展开「高级配置」，找到「机器人约束」卡片内的选择框。同一区域还有「通用配置」和「容器约束」；多个控件可能都显示“请选择”，定位时使用字段所属卡片。 |
| 设置参数 | 读取已有值和展开后的选项，按用户要求选取并核对结果。若控件支持多选，按请求区分追加、移除、替换。目标值已满足时直接报告当前值。 |
| 确认修改 | 需要应用修改时，使用面板底部的「确定」，观察校验提示及面板状态。若只要求查看配置，读取字段后用「取消」退出。 |
| 验证保存 | 面板确认和整图保存分别核验。截图只展示了面板按钮；根据当前页面的控件提示与待保存状态判断是否还有地图级保存步骤。确认已提交后重新打开同一地图、同一点位和字段，回读约束值。结果不明时先查看当前值与待保存状态，再决定是否重试。 |

仅取得表单回显时，报告“面板已显示目标值”。只有在重新打开地图后读到目标值，才报告“已保存并回读”。后续可在本节补入真实的点位定位方式、下拉选项规则、整图保存入口和成功提示。
