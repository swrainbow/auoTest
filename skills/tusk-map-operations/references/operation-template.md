# 新增一个模式操作

将下列字段写入对应模式文档的一个小节。用界面原文命名操作和字段，便于后续按标签定位。

| 字段 | 填写内容 |
| --- | --- |
| 操作名称与目的 | 例如“修改点位的容器约束”。说明操作完成后，用户应看到什么。 |
| 适用模式 | 填顶部菜单项。如已知依赖标准或专业模式，注明左下角选择。 |
| 目标与参数 | 填地图、对象的唯一标识、输入字段及取值规则。有追加和覆盖之分时，写明各自的操作。 |
| 入口与步骤 | 从已知页面状态开始，逐步记录控件名称、所在面板、触发方式及下一步出现的标志。 |
| 完成与核验 | 查看操作写明读取哪个结果；修改操作写明生效范围、提交入口，以及如何重新找到同一对象并核对结果。 |
| 待核实项 | 记录截图未覆盖的步骤和还需观察的界面。实测后用实际步骤替换。 |
